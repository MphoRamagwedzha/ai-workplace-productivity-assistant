## Project Overview
The AI Workplace Productivity Assistant is an AI-powered platform designed to help people work more efficiently by bringing common productivity tools together in one place. It aims to reduce time spent on routine tasks, make information easier to understand, and help users focus on their priorities.

This project was built as part of the ALX Final Project.

## Features Implemented
The application includes at least 5 AI productivity tools:

### 1. Smart Email Generator
- Generate professional emails quickly
- Support multiple tones (formal, friendly, concise)
- Draft replies and improve email clarity

### 2. Meeting Notes Summarizer
- Summarize lengthy meeting notes and transcripts
- Extract action items, decisions, and key points

### 3. Task Prioritizer
- Organize tasks and identify priorities using AI suggestions

### 4. Document Analyzer
- Analyze and summarize long documents, extracting key insights

### 5. Focus Timer
- Help users stay focused and track productivity with a built-in timer
